# Design Document

## Overview

This design finalizes the shift from the prior SveltePlot implementation to an echarts6-centric stack for Bases chart views. We will eliminate legacy dependencies, align the `svelte-echarts` wrapper with echarts6 (either via peer override or wrapper replacement), and deliver an in-view floating configuration stack that exposes comprehensive echarts6 options without relying on naive JSON overrides. The solution adheres to `.codex/steering/product.md`, `.codex/steering/tech.md`, and `.codex/steering/structure.md` by preserving existing chart workflows, Bun/Vite tooling, and the established `packages` module boundaries. ECharts 6 adoption leverages the dataset and renderer enhancements highlighted in the latest release notes to improve interactivity and performance for large Bases datasets.

## Architecture

- **Dependency Layer**
    - Remove legacy chart wrappers, including `svelteplot` and `svelte-echarts`, from `package.json` and purge related import paths.
    - Adopt `@ticatec/uniface-echarts` as the sole chart wrapper dependency; configure Bun/Vite aliases if needed to align existing imports with the new wrapper.
    - Ensure echarts6 is the only resolved version by pinning `echarts@^6.0.0` and verifying `bun.lockb`.
- **Runtime Layer**
    - Centralize echarts bootstrapping in a new `packages/obsidian/src/echarts/runtime.ts` that exposes:
        - `ensureRuntime()` for theme registration (migrated from `theme.ts`).
        - `createChartInstance()` for consistent init, resize, and disposal handling with `@ticatec/uniface-echarts`.
    - Update `EChartsPlot.svelte` to consume the runtime helpers and emit typed lifecycle events for the config stack through the new wrapper.
- **Configuration Stack**
    - Add a `packages/obsidian/src/charts/config-stack/` module containing:
        - `ConfigStackHost.svelte` — floating container anchored within the chart viewport with auto-hide, show/hide toggle, and portal-safe focus traps.
        - `ConfigPanel.svelte` — composite of sectioned controls (axes, series, datasets, interactivity, theming).
        - `stackController.ts` — orchestrates visibility timers, pointer tracking, and keyboard shortcuts.
    - Embed the host inside `PlotGridItem.svelte` to keep per-view customizations local to each chart instance and avoid the Bases top bar.
- **Data Orchestration**
    - Introduce `packages/obsidian/src/echarts/dataPipeline.ts` to translate `ChartView.processData()` output into echarts6 datasets/series, replacing legacy override utilities.
    - Expose a `buildOptions(state, pipelineResult)` function that merges base config, advanced overrides, and stack-driven updates without JSON string injections.

## Components and Interfaces

- **`ConfigStackHost.svelte`**
    - Props: `chartId`, `initialState`, `autoHideMs`.
    - Emits: `toggle`, `applyConfig`, `revert`.
    - Uses a pointer-leave debounce to trigger auto-hide and a focus-visible indicator for accessibility.
- **`ConfigPanel.svelte`**
    - Receives strongly typed sections (e.g., `AxisConfig`, `SeriesConfig`, `TooltipConfig`).
    - Renders reusable control primitives (switches, sliders, JSON editors for advanced segments) drawn from existing style tokens in `styles.css`.
    - Writes normalized patches to the centralized data pipeline via `applyConfig`.
- **`stackController.ts`**
    - Holds state machine for `visible | hiding | hidden`.
    - Provides `withAutoHide(fn)` decorator to reset timers on pointer activity.
- **`runtime.ts`**
    - Interface `EChartsRuntime` exposes `init`, `setOption`, `dispose`, `onError`.
    - Ensures instances share a single echarts6 import, easing testing and elimination of legacy shims.
- **`dataPipeline.ts`**
    - Exposes `buildDatasetFromBase(dataWrapper: DataWrapper): PipelineResult`.
    - Normalizes series meta (group keys, labels) and ensures compatibility with echarts6 dataset/link features.
    - Supports incremental updates triggered by Bases `QueryController` events.
- **Existing Files Updated**
    - `ChartView.ts`: wires the pipeline and stack controllers, removes references to `ECHARTS_OVERRIDES`.
    - `options.ts`/`config.ts`: restructured to consume pipeline outputs rather than naive merges.
    - `EChartsPlot.svelte`: migrates to `<UnifaceChart>` (from `@ticatec/uniface-echarts`) with injected runtime helpers; legacy wrapper code paths are removed.

## Data Models

- **Pipeline Types**
    - `PipelineResult` encapsulates `datasets`, `series`, `visualMap`, `toolbox`, and mutability flags needed by echarts6.
    - `ConfigPatch` union types describe the mutations generated by the stack; patches map to specific requirement IDs (e.g., axes -> Requirement 3 AC1).
    - `ChartState` persists last-applied configuration per view, stored in existing Bases view settings to maintain parity with current workflows.
- **Normalization Rules**
    - All incoming Base fields pass through `parseValueAsX` and numeric validators from `packages/obsidian/src/utils/utils.ts`.
    - Grouping metadata uses `ChartData.ts` helpers to avoid duplicating logic; the pipeline augments them with echarts6 dataset IDs.
    - Advanced features (brush, sampling, dataset transforms) derive from echarts6 APIs referenced in Requirement 3 and loaded dynamically to limit bundle cost.

## Error Handling

- Runtime helper wraps echarts initialization with descriptive errors surfaced via the existing fallback UI in `EChartsPlot.svelte`.
- Config stack validations:
    - Pre-submit validation ensures incompatible option combinations fail fast with inline messaging.
    - Pipeline rejects patches targeting deprecated SveltePlot structures and logs migration errors via shared logging utilities.
- Dependency guard:
    - Build-time script verifies absence of `svelteplot` imports and asserts echarts version by reading `bun.lockb`.
    - CI lint rule to prevent reintroduction of naive JSON overrides.
- Auto-hide UX:
    - Controller cancels hide timers on pointer re-entry to avoid unintended loss of focus.

## Testing Strategy

- **Unit Tests**
    - `tests/echarts/dataPipeline.test.ts`: validates dataset normalization, grouping behaviour, and error handling for malformed data.
    - `tests/charts/configStack.test.ts`: verifies auto-hide state transitions and config patch emission.
- **Integration Tests**
    - `tests/charts/chartView.integration.test.ts`: mounts `ChartView` with mock Bases data, asserts echarts6 instance creation, and evaluates config application end-to-end.
    - Smoke test to render large dataset scenarios leveraging echarts6 dataset transforms (in line with release guidance).
- **Tooling**
    - Extend `bun run check` by adding a custom script that greps for forbidden legacy imports.
    - Add snapshot tests for generated echarts options to detect regressions in stack-controlled mutations.

## Research Summary

- Svelte wrapper options: `@ticatec/uniface-echarts` offers multi-platform support and can serve as a replacement if maintaining a fork is impractical
- ECharts upgrade context: Recent release notes highlight enhanced dataset handling and rendering optimizations, informing our testing and pipeline design
